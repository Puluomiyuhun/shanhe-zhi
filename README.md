# 山河志 · Shanhe Zhi

以三国时代为背景的浏览器策略游戏原型，探索「单武将扮演 + 三维大地图」的组合。

当前版本：**五方势力 / 14 城演练版 · 旗牌与军令界面更新**。

## 开始体验

无需安装前端依赖，也没有构建步骤。需要 Python 3 和支持 WebGL 2 的现代浏览器。

在仓库根目录启动静态服务器：

```sh
python -m http.server 8080 --directory dist
```

Windows 也可以使用 `py -m http.server 8080 --directory dist`。

- 三维战区：http://localhost:8080/lab/
- 原版二维地图：http://localhost:8080/

请通过 HTTP 服务器运行，直接双击 HTML 文件无法正常加载 ES 模块。

## 本版内容

- 11,648 个六角地块，程序化山川、树林、河道与城池。
- 刘表、袁术、张鲁、曹操、孙坚五方势力及 14 个城池。
- 拉远查看势力疆域，拉近查看地块和建筑；城市侧栏、情报总览、武将列表。
- 操纵沈行舟部队进行寻路、逐格行军、占地与补给演练。
- 自适应城市旗牌、实时部队军令与补给提示、城郊控制态势。
- 原版二维游戏与三维演练相互独立。

城址、势力归属与武将配置服务于原型验证，不是某个历史年份的精确复原。全国 AI、正式战斗、外交、角色成长等尚未接入三维版本。

## 操作

| 操作 | 功能 |
| --- | --- |
| 滚轮 | 缩放地图 |
| 左键拖动 | 平移镜头 |
| 右键拖动 | 旋转镜头 |
| 点击城名 | 在右侧查看城市情报 |
| 点击地块 | 预览行军路线 |
| 确认行军 → 推进 | 开始执行军令 |
| 空格 | 暂停或继续 |
| 右键轻点 / Esc | 取消路线预览 |

首次游玩可点击「前往新野」，确认路线后经渡桥北上；抵达后展开「兵站演练」，测试封锁后方和恢复补给。

## 项目结构

```text

  lab/                三维战区
    world.js          地形、城市、势力、寻路与补给
    main.js           Three.js 场景与交互
    art.js            程序化建筑、植被和材质
    overview.js       近景与远景过渡
    sidebar.js        城市侧栏
    intelligence.js   情报窗口
    roster.js         武将列表
    clarity.css       字体与势力标识样式
    command.css       情报旗牌与军令界面样式
    assets/           临时头像与出处说明
    vendor/           本地 Three.js 及其许可证
verify-*.mjs          地图逻辑验证脚本
*.md                  设计草案和迭代记录
```

## 验证

需要 Node.js 22 或更新版本：

```sh
node verify-expansion.mjs
node verify-factions.mjs
node verify-actors.mjs
node verify-density.mjs
```

覆盖地块拾取、渡桥路线、补给封锁与恢复、城市归属、全部城池可达性。

## 自主武将演练

点击「推进」可观察六名武将带兵巡防、出征返军或独自周游。在「武将动向」侧栏查看目的地与定位；驻城主角仅在城牌显示「主」。AI 出征目前尚不结算战斗或攻城。验证脚本覆盖五分钟行动循环及旋转投影一致性。

## 城池密度更新

保持 11,648 格尺寸，扩充至 35 城、9 势力，补齐可玩地图四周。拥挤名牌保留阵营小旗，悬停展开。新增地形计算优化和城市侧栏寻路缓存。本机 1280×720 默认画质远景及六 AI 近景样本约 60 FPS；详细口径与限制见 [城池密度与性能记录](城池密度与性能记录.md)。

## 地图鼠标操作

左键查看地块或城市情报；右键地块或城牌立即移动并自动推进，无需再次确认。右键拖动旋转、左键拖动平移，空格暂停／继续。游戏区域屏蔽网页右键菜单。
