# 春秋群英独立剧本

2026-09-24。用户选择跨时代名臣同台；不对应一个历史年份。

## 入口和隔离

通过 `/chunqiu/` 进入；默认 `/` 与 `/lab/` 仍是三国。春秋场景独立保存逻辑、样式和数据，只复用 `../lab/vendor/three.module.js`。本轮原三国文件与默认入口逐文件 SHA256 校验未变。后续修复须明确同步哪一个场景，两个副本不会自动同步。

## 规模

28 方势力、38 座城邑、146 位卿士、6,708 个六角格。晋、楚、齐、秦、周、宋、鲁、郑、卫、陈、蔡、曹、许、燕、吴、越，以及莒、邾、滕、薛、杞、徐、曾、巴、蜀、虞、虢、邢。曾与随不重复设置。

齐桓公、晋文公、楚庄王、秦穆公、宋襄公和吴越人物同台。四名原创配角为徐闻、巴衡、蜀简、邢泽；巴曼子、鳖灵标为传说人物。主角姬衡为原创晋国士人，另计。能力、驻地、国境是游戏配置，不是史实资料；地图只保留压缩后的区域关系，未使用精确古城坐标。

## 已实现与边界

沿用右键直接移动、左键情报、空格暂停、连续行军、补给演练、远近地图与人物列表。五支 AI 部队（先轸、成得臣、孟明视、王子城父、孙武）和五名独行人物（子产、晏婴、季札、子贡、范蠡）执行巡行、抵近、出使式游历。146 人是名录规模，不代表146个同时活动的地图实体。出征仅抵近返回；尚无正式战斗、外交会盟、拜访或成长系统。

人物使用姓名章，主角使用原创 SVG 纹章；没有用三国人物头像冒充春秋人物。地形规模缩小，势力按城市距离加权染色，较大诸侯获得更大区域。不是精确历史疆界。

## 验证

`node verify-chunqiu.mjs`：所有38城可达且至少2名初始驻留人物；人物名称唯一、能力范围有效；180秒模拟中10名AI均行走；主角到曲沃路线成功。浏览器验证势力/驻城筛选、管仲详情、曲沃右键路线与空格暂停；控制台无错误。

后台标签页18秒缩放测试受浏览器限速，只有16个帧样本、约1 FPS，不可作为前台性能结论。CPU P95约1.9毫秒亦仅为该后台样本。需前台实机测试GPU和帧时间，不能声称稳定60帧。

## 河山与关隘细化（2026-09-24）

本轮只修改春秋。地图仍为 6,708 格、38 城、28 势力、146 人；三国63个原文件和根入口 SHA256 校验未变。

- 秦国城址向关中内部调整、势力分区采用东西向权重；燕国采用东西展开的分区权重，国名移至腹地。边缘染色的消隐带由约8格坐标单位缩至约3，避免边缘国家显得被削去。仍是加权分区，不是历史疆界数据。
- 黄河改为河套局部—晋陕之间南下—折东—古下游北趋的概化曲线；补长江巴蜀—三峡—江汉—下游弯曲主干、渭水和汉水。没有声称复原某年古河道；此轮没有真实海岸、湖泊或DEM。
- 山脉改为秦岭、太行、燕山、陇山、川西群山、大巴山、巫山与方城地带；移除原有横贯地图的假河、中央直路和每座城纵向贯穿山脉的自动平整走廊。
- 5处可通行隘口：崤函通道、秦岭谷道、方城隘口、太行陉道、巴蜀山道。这些是地理演练名称与位置，不代表对应历史关城在同年存在；没有直接使用后世潼关、剑门关等关城编制。
- 12处津渡以岸边码头和渡舟示意，非跨越大江的大桥。普通河格不能走，山地有成本，险山不可走，关隘谷道可通行。尚未加入守关驻军、关隘控制权或战斗。
- 曾国从原来的长江以南错误位置移至江北随枣方向；调整巴城避开河岸。所有城市中心距水岸超过3个世界单位。

技术：`geography.js` 统一河线、岸距空间索引、渡口与通道定义，供水面、地形、寻路复用。512²单通道河道遮罩避免六角染色三角形盖住窄水面；水面不画网格。谷口平滑衔接坡面。中景可读山河与关隘名称；超远景沿用仅国名，近景保留城市交互。

验证：`node verify-chunqiu.mjs` 通过（全部城市可达、全部AI行动）；`node verify-chunqiu-geography.mjs` 通过（4水系、12津渡、5隘口、498河格、水面/河床一致、城池不压河）。秦到蜀52格，测试中关闭山口后绕行128格；关闭所有渡口后秦晋路线不可达。这些封闭操作仅在测试世界中进行，未新增玩家关隘封闭指令。浏览器检查远景城牌隐藏、河水清晰、近景恢复及无控制台错误。未做前台GPU帧率基准，不将后台标签页数值作为性能结论。

## 支流、湖泽与道路细化（2026-09-24）

用户接受有考据依据的合理推测，不要求精确历史坐标；继续保持三国版本不变。

新增汾水、泾水、洛水、淮水、泗水、岷水，总计10条河流；3片不规则湖泽为震泽、大野泽、云梦湖沼。轮廓均为手工概化，尤其云梦只画作江汉之间的一小片代表性湖沼，不能视作古云梦泽范围复原。淮水保持独立东流，未照搬现代洪泽湖；彭城北移少量地图距离，避免淮水/长江挤到一起并保持城址在河岸之外。

补嵩山、桐柏山、泰沂丘陵、会稽山地、巴蜀丘陵共5组地貌；新增轘辕山道与鲁南谷道，总计7处隘口。增加8处渡口，总计20处；所有渡口必须可达。关隘名称只是本剧本的通路示意，不宣称对应历史关城的确址。

14段区域道路由有效寻路生成，连接河汾、关陇、崤函、王畿、郑宋、齐鲁、泗上、江汉、吴越、巴蜀与燕南等地；不是已考证的古道路网。所有路段先按未打折的地形生成，再统一给地块降成本，不会为了画路挖穿险山或湖面。普通道路成本0.75，山路1.6（原山地2.4）；湿地2.2。湖泊不可步行，湖边湿地可缓慢通行。道路转弯只做视觉平滑，模拟仍沿有效六角格。

渲染：湖面共用水面批次；岸边芦苇实例化；道路一批合并网格，收窄、土色、圆滑转角，避开水面；树木避开道路格。地理标签避让城牌及其他标签，超远景全部收起，保持国名总览。此轮不增加地图/人物规模，未宣称前台帧率结果。

验证：两个春秋验证脚本通过。10河、3湖、14道路、20津渡、7隘口，724个河流格；38城及所有渡口、隘口可达。道路格相邻且全部可走；湖泊不可走；全部城市中心距水岸大于3个世界单位。关闭山道后秦蜀路线54格变127格；关闭渡口后秦晋不能直达。10名AI持续行动。浏览器查看吴地湖岸、道路、地理标签避让及远近切换，无控制台错误。原三国63文件校验未变。
