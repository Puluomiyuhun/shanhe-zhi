# 军令与情报界面改进 · 2026-09-24

## 行为

- 左侧是本队命令：行军（提示右键选目的地）、返回襄阳、原地待命、推进一刻。
- 右上角集中势力、城市、武将、部队、军情。城市进入列表；地图点城仍更新侧栏。
- 势力为比较表，点击转到该方城市；城市表支持势力筛选，同窗右侧预览、地图定位和立即移动。
- 武将保留能力列排序和势力筛选，改用轻暗底、细线、金色选中标记与无衬线文字。
- 部队表包含主角和三支 AI 部队；不带兵的周游者在武将列表查看。
- 地图武将旗牌悬停或键盘聚焦出现小情报卡，展示所属、兵力、军令、目的地、路程、行动原因；点击固定到侧栏。驻城仍隐藏旗牌。

## 实现

`dist/lab/interface.css` 是本轮最终覆盖层。`map-peek.js` 使用一张独立浮层，不改投影旗牌尺寸；仅在展开时刷新内容（180 ms）及跟随位置。离开、入城、打开对话框或 Esc 隐藏。注意全局 footer 样式，需要在卡片内显式复位。

城市列表寻路按世界对象、玩家格子与封锁状态缓存，换选中行不重新计算所有路线。仍为主线程首次计算，非全国规模性能优化。

## 验证

浏览器 1280×720 检查城市筛选、行预览、操作区可见性、武将筛选与排序、四支部队列表、键盘聚焦展开卡片。测试右键新野下令、空格暂停、待命取消、返回本营和推进一刻；未发现控制台错误。连续行军与军令路线回归脚本通过。指针悬停与聚焦共用展开逻辑；自动浏览器没有独立 hover API，截图以聚焦路径检查。

未接入交战、拜访、任务结算或新属性系统，本轮聚焦可执行命令和情报浏览。
