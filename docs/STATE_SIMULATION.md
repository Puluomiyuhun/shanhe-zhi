# 国家模拟 v2：列国演化与城郊营建

2026-09-24。适用于 `/game/?scenario=chunqiu` 与 `/game/?scenario=sanguo`；原 `/lab/` 独立三国保持不变。本说明取代旧记录中“共用引擎没有内政、外交与攻城”的描述。

## 使用

点击「推进」或空格，所有国家开始演进。无军令时玩家本队驻留，但国家仍自行决策。「1×」按钮依次切换 3×、8×；1× 下每 2 秒推进 1 旬。左侧「推进一旬」暂停实时推进，完成本队下一格并推进国家一旬。打开情报暂停世界，关闭后需手动继续；切后台暂停，不补算离线时间。

- 势力：各国城数、钱粮、兵力、政策和外交概况。
- 外交：交战、盟约、停战期限。
- 城市／地图点击城市：实时归属、府库、粮草、守军、城防、民心、内政项目、首领、忠诚和城郊设施。
- 部队／地图旗牌：实际兵力、目标、出征／迎战／交战／攻城／撤军状态。悬停仍使用固定浮层。
- 军情：最近 100 条纪事，含旬数。地图下方播报宣战、盟约、易主和停战。

## 规则

城邑每旬产出钱粮、承担驻军粮耗，根据粮草、城防、威胁与驻军数选择屯田、修筑、征募、兴商或休养。征募、修筑、出征消耗真实库存。数值为原型平衡参数，没有历史财政量纲。

国家轮流评估邻近城邑、实力和外交；发动战争后才可派兵攻取。出征扣除出发城守军，迎击或援军同样从城邑抽兵，不凭空生成。国家最多一个攻取队、一个迎击队，另有一个工役队槽位；全局最多18支活动军事部队、8支工役队；人物游历保留，不再同时运行旧固定巡防部队。

军队沿现有可达地格连续行军；野战以距离触发，每旬同时结算双方伤亡，统率、士气、兵力和部分地形影响战力。到敌城后结算守军伤亡和城防损耗；守军归零则易主，并接收该城初始辖区内原属守方的土地。留驻部分兵力，其余回城。余部回到己方城后重新并入守军。损耗过大、士气低、断粮或停战会撤军；国家最后一城失守后退出，残部解散。没有详细兵种克制、阵型、包围、战术指令与攻城器械。

盟约48旬，每国最多2个盟友；盟友互不侵犯，遇敌可宣战援助、派出实际援军，但受兵粮和部队上限约束。无递归的无限联盟连锁。战争持续36旬后自动议和休兵18旬，停战期内不得再次宣战。对手选择和外交目前为确定性启发式规则，不复演史实，不代表成熟战略AI。

## 架构与一致性

- `dist/engine/campaign.js`：纯模拟、城邑运行副本、国家策略、外交关系、军队、战果；不依赖DOM和计时器。
- `simulation.js`：把原游历AI与国家军队组合成原视图使用的 actors/advance/position 接口。
- `campaign-ui.js`／`campaign.css`：国家、外交与城市经济展示。
- `main.js`：同一暂停状态与倍率控制本队、游历和国家；只有战果 revision 改变时重建地盘染色，按旬更新城牌数据。重置会重建全部状态和国家标签位置。
- 城池初始坐标与归属仍在剧本中；运行归属在 `world.cities`／`simulation.campaign.cities`。禁止修改 `scenario.cities`，否则新一局、地形和测试会被污染。地形始终使用初始坐标。
- 城市情报与筛选使用运行归属；失国的国名按钮禁用，空城市筛选不报错。首领叛变／流浪会更新对应人物的运行隶属与驻地；其他人物不会自动跟随，失去原驻地的静态人物在名簿中概化到本国其他城、无城则标「流散」，未实现俘虏与招降。
- 玩家本队尚未接入自动战斗或国家征募系统，是独立行军验证部队；经过敌城不能直接改城址归属。原走格占地和补给演练保留，非完整军事权限系统。
- 四片外围族群只是分布图层，不参与财政、外交和战争。
- 无持久化存档，刷新、换剧本或重置会重新开始。不可向用户承诺长期战役保存。

## 性能与验证

固定模拟小步最长100ms，旬边界精确切分；每旬轮询4国决策。军事部队上限18、工役队上限8，寻路缓存最多128项；不存在每帧全国家重新寻路。国家和部队槽位按需扩展但有总量上限，军情最多100条。国家部队模型复用，闲置时隐藏。尚未做渲染GPU的正式基准，不把纯逻辑耗时当成帧率。

`node verify-campaign.mjs` 在两种 SCENARIO 下验证500旬演进、非负资源、兵力守恒、出征扣兵、返军归还、战争／盟约／停战、城池与地格归属、兵粮不足拒绝出兵、玩家路过不无战占城、封锁不改城、初始数据隔离、重置及时间切分一致性。

v2 固定种子测试中，两剧本500旬均产生了建设、自立和流浪筑城事件。数字为该规则版本的确定性测试轨迹，平衡修改后可以变化，不是验收硬编码目标。旧 `verify-scenarios.mjs`、`verify-chunqiu.mjs` 继续检验地理可达和旧AI基础；旧脚本中的“10个AI”是旧行动定义数，不是当前共用引擎实际活动军队总数。

浏览器验收：时间倍率、真实推进、外交表、国家资源表、城池经济、军队旗牌、城市空筛选、暂停与重置；检查无控制台错误。后续优先考虑玩家接军令与参与战斗、战争疲劳与人口约束、长期存档，再扩大AI复杂度。


## v2：政治变动与流浪筑城

`evolution.js` 通过 campaign 上下文复用行军、军队和城市归属转移，不更改剧本初始数据。运行国家列表现在是 `campaign.factions`，城市是 `campaign.cities`；界面不得继续从静态 scenario 列表枚举。世界模块的 faction resolver 只为当前界面解析新增国色，纯模拟使用自己的 resolver，避免多世界测试互相污染。

- 城邑有首领和忠诚。战时和低民心缓慢降低忠诚，和平稳定时恢复；第48旬后每8旬有7%的全局政治事件尝试，满足忠诚、人物空闲等条件才触发。成功事件间隔至少48旬，同城至少60旬。
- 政治事件中45%尝试自立，其余归附最近的其他国家。自立使用城名命国、分配新色；原国若尚存，可按外交规则宣战。旧有盟约／停战仍然有效，不强行破约。领土、城池库存、守军及已完成设施一同移交；未完成工程取消，原工役队返回本国其他城或失国解散。
- 第48旬后每12旬有5%的全局流浪尝试，成功间隔至少72旬。只选兵力至少900且粮草充足的在外军队；同时最多2支流浪势力。转移现有兵力与粮草，不生成额外士兵。
- 流浪军先找到距离其他城17单位以外、地形平坦且可达的边地，实际行军到达后筑城8旬。70旬内未完成或兵力不足则解散；断粮仍会损兵。
- 新城将余部转为守军，剩余随军粮草入库，并获得300初始府库（抽象安置资源）。划出半径7的少量辖地，清理旧省份映射后加入新省份；以后继续参与内政、建设、征兵、战争。新国／新城命名为程序生成，明确属于架空演练。
- 一局累计最多新增8国、6城，不会无限繁殖；新国灭亡不回收这个名额。固定默认随机种子便于复现，可通过 createCampaign 的 options.seed 调整。低概率不保证每局短时间内发生；现阶段重置同一剧本会复现同种子轨迹。

## v2：城郊营建

开局装饰由春秋71处、三国61处减少为春秋10处、三国9处旧有聚落；旧聚落仅作景观。功能设施全部由国家之后建设。每城各类最多一处，总计3处；没有安全、可达且属于本国的平地时可以不建满。

|设施|府库成本|施工粮草|到场施工|效果|
|---|---:|---:|---:|---|
|屯田|500|450|5旬|每旬粮草 +100|
|市集|650|350|6旬|每旬府库 +65|
|军营|600|550|6旬|每次征募 +30，守城造成伤亡 +10%|

另抽调280名守军与450随行粮草。工役队从出发城沿真实路径行进；路上不计施工、不提前产出。完工后沿路归营，剩余士兵与粮草返还。工地遭敌军逼近、地块失守、主城易主、工役队溃散／撤退时取消未完工程，已付成本不返还。已完成设施只有地块仍属城市所属国时提供加成；改变城市归属不会凭空补齐失守地块。

建设决策分布在原每旬4国轮询中，不逐帧规划。平地候选缓存，行军路线缓存复用。`evolution-view.js` 只在设施／新城变化时重建动态建筑批次，按材质合并绘制；田垄沿地形采样，无大块浮空底板。新增城址／工地清理附近实例树木，重置恢复树木原矩阵。动态军队模型按需创建，重置释放各队独立材质、模型和标签。

## v2 验证与边界

运行 `node verify-evolution.mjs`，并以 SCENARIO=sanguo 再运行，检查：真实施工与归营、完工才加成、叛变及自立、工地取消、不可达不扣钱粮、流浪实际行军筑城、新城再建设、兵力守恒、动态军队集合、名簿隶属、重置和初始数据隔离。`verify-campaign.mjs` 两剧本各500旬，继续检查财政、战争、外交和时间切分。模拟耗时只反映CPU逻辑，不能当GPU帧率。

浏览器检查过自然演进到第275旬：出现叛变、流浪新城、自立新国；39城列表、新城定位、领土颜色、国名、人物驻地与设施显示均同步，控制台无错误。原 `/lab/` 未改。尚无存档、俘虏招降、国家灭亡后复辟、人口约束和设施升级；玩家依旧只控制自己的行军队，建设与政治变动由国家AI驱动。


## 2026-09-24 兵站与地图平移

军营扩展为兵站（内部 kind=camp），每城最多一座，沿用现有工役队、建设成本和全局军队上限。兵站每旬从所属城调粮最多180、保留城粮1200，容量1800；不生成免费粮食。敌军6距离内停止整备和调粮。安全时完整度每旬恢复2。

AI出征可经顺路兵站集结2旬；缺粮或低士气可去22距离内己方兵站休整5旬，14旬冷却，不凭空恢复兵员。每旬至多补240粮、恢复10士气，然后恢复原军令。AI优先评估附近敌国兵站，袭击沿真实路径执行；附近敌军数量提高威胁评分，守方沿用迎击逻辑。毁站焚毁粮储，24旬内不重建。停战、易主、敌军逼近会取消整备或袭击。主角可左键兵站看侧栏，点击集结或右键前往；停驻且推进时每旬消耗60粮恢复8士气。主角仍不参加AI自动战斗，不可把休整解释成补充兵员。

减法：无建筑等级树、运输队、全地图实时补给网络、独立驻站军队槽；兵站结算按旬，不在渲染帧扫描。地图模型仅设施变化时按材质合批。复用既有农商军三类设施。

平移优化：输入合并到动画帧，释放鼠标时补最后位移；投影只更新根节点矩阵，避免额外递归整棵场景树；隐藏地理标签跳过投影；AI旗牌文字/颜色/状态只在变化时写DOM；标签使用translate合成提示；取消右侧栏对移动地图的实时背景模糊。没有通过降低地图规模解决问题。

新增 verify-depots.mjs：施工、有限粮储、军队休整恢复原目标、重复命令防护、主角恢复、敌军阻断、袭击摧毁及重建冷却。两剧本 verify-campaign.mjs / verify-evolution.mjs 各500旬通过，原有兵力守恒仍成立。操作说明→样区说明增加18秒平移评测；测的是浏览器镜头往返，不等价于不同显卡上的保证帧率。原 /lab/ 保留不变。
